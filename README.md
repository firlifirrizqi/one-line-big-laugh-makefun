Entry for the [One Line, Big Laugh](https://make.fun/competitions/u-coral-404-one-line-big-laugh-328fb857) competition on make.fun.

`main.py` (stdlib only) writes a single funny line of at most 200 characters to `/output/entry.txt` and verifies it against the gate: UTF-8 text, 1–200 characters, not only whitespace, and byte-identical on read-back.

## Run

```sh
python3 main.py
```
